# machine_learn_0311

Este repositório contém notebooks focados no domínio das ferramentas fundamentais para análise e visualização de dados em Python. O objetivo aqui é consolidar o conhecimento sobre a manipulação de estruturas de dados complexas e a geração de insights através de gráficos estatísticos.

## 📂 Conteúdo

* **pandas.ipynb**: Explora a biblioteca Pandas para manipulação de DataFrames. Inclui leitura de arquivos CSV, filtragem de dados (como a análise de sobreviventes do Titanic), seleção de colunas e operações de agregação.
* **matplotlib.ipynb**: Focado na biblioteca Matplotlib para visualização de dados. Demonstra a criação de diferentes tipos de gráficos (dispersão, linhas, etc.) para interpretar tendências e padrões nos conjuntos de dados estudados.

## 🛠️ Tecnologias e Bibliotecas

As ferramentas utilizadas nestes projetos são:

* **Python 3**: Linguagem base.
* **Pandas**: Biblioteca líder para manipulação e análise de dados estruturados.
* **Matplotlib**: Biblioteca principal para geração de gráficos e visualizações estáticas ou interativas.
* **Jupyter Notebook**: Ambiente para execução de código e documentação em tempo real.

## 🚀 Como começar

1.  Clone este repositório:
    ```bash
    git clone https://github.com/felipe-r-regiani/machine_learn_0311.git
    ```
2.  Instale as bibliotecas necessárias:
    ```bash
    pip install pandas matplotlib
    ```
3.  Execute os notebooks para ver a análise de dados em ação:
    - Abra o `pandas.ipynb` para ver a filtragem de dados do Titanic.
    - Abra o `matplotlib.ipynb` para visualizar os gráficos gerados.
